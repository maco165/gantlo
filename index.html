gantlo — ガントチャートで計画する API と HTTP の基礎

gantlo は、ブラウザに URL を打ってから画面が出るまでの「リクエストの旅」に沿って、API と HTTP の基礎の規格を学ぶ学習サイトです。 名前は、ガントチャートと、1969 年に ARPANET で最初に届いた 2 文字「lo」から取りました。

学べること

  • 本編 4 週: HTTP・URI・JSON・MIME・UTF-8 / DNS・TCP/IP・TLS / REST と OpenAPI / OAuth 2.0 と JWT
  • 追加のコース: Spring Boot の流れ、技術の歴史、管理の歴史、セキュリティ

進み具合はブラウザの localStorage にだけ残り、サーバーには送りません。表示には JavaScript を使います。
